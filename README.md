## What this project is

An interactive JavaScript app built with vanilla ES6+ and the DOM API, written to satisfy the user stories set by
freeCodeCamp for this certification project. It is part of the JavaScript v9 curriculum,
whose certification requires completing all coursework plus this set of certification projects
and passing the certification exam.

- **Curriculum:** freeCodeCamp JavaScript (v9)
- **Project type:** Certification project
- **Tech stack:** JavaScript, HTML5, CSS3
- **Challenge page:** <https://www.freecodecamp.org/learn/javascript-v9/lab-weather-app/lab-weather-app>

## Project files

- `index.html` — page markup and structure
- `script.js` — application logic
- `styles.css` — styles and layout

## How to run

Open `index.html` in any modern browser — no build step, no dependencies.

```bash
# optional: serve locally
npx serve .
```
